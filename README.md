# Sri Shakthi Driving School Website

Static, mobile-responsive website for Sri Shakthi Driving School, Madambakkam, Chennai.

## Files
- `index.html` — website
- `styles.css` — design and responsive styles
- `script.js` — mobile menu and current year
- `assets/logo.png` — supplied school logo

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `sri-shakthi-driving-school`.
2. Upload all files and folders from this package.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live website URL.

The site is a static website and does not require a server.
